## 📖 Sobre nosotros

TerraNovaMCDev reúne el código y las herramientas detrás de **TerraNovaNetwork**: un servidor survival con pueblos y naciones (Towny), economía, gremios, misiones, mazmorras y contenido personalizado.

Aquí se desarrollan los plugins propios del servidor, el panel web del staff, los bots y la infraestructura que lo sostiene todo.

## 🎮 El servidor

| | |
|---|---|
| **Versión** | 1.21.10 |
| **Modalidad** | Survival · Towny · RPG |

**Características principales**

- 🏰 Pueblos y naciones con Towny
- ⚔️ Gremios y modo guerra
- 💍 Sistema de accesorios (anillos, collares…)
- 📜 Misiones y códice
- 🐉 Mazmorras, jefes y mobs personalizados
- 🛠️ Encargos de crafteo entre jugadores
- 💰 Economía y regiones comerciables

## 🧩 Proyectos

| Proyecto | Descripción | Tecnologías |
|---|---|---|
| **Panel web** | Panel de gestión del staff con roles, sanciones y tablero de tareas | Node.js · React · MariaDB · Docker |
| **Bot de Discord** | Integración con Discord y ejecución remota | Python · Flask · Docker |
| **Resource pack** | Texturas, modelos e iconos personalizados | Blockbench · ItemsAdder · ModelEngine |

## 🤝 Contribuir

1. Haz un fork del repositorio o crea una rama desde `main`.
2. Usa commits descriptivos (`feat:`, `fix:`, `refactor:`…).
3. Abre un Pull Request explicando los cambios.
4. Espera la revisión de un miembro del equipo antes de fusionar.
